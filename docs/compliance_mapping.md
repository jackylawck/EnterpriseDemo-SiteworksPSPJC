# Compliance Mapping (合規與內控對應矩陣)

本系統 `EnterpriseDemo-SiteworksPSPJC` 的設計初衷，是為了將高風險的工地施工作業透過數位化手段，強制對齊香港及國際的職業安全與健康規範。

## 1. 適用法規與標準 (Applicable Regulations & Standards)
* **香港《職業安全及健康條例》(OSHA - Cap. 509)**：雇主必須在合理切實可行範圍內，確保其所有在工作中的僱員的安全及健康。
* **香港《工廠及工業經營條例》(Cap. 59)**：針對高空工作、密閉空間、起重機械操作等高風險作業的專項安全規定。
* **ISO/IEC 27001:2022**：資訊安全管理系統 (ISMS)，確保安全稽核紀錄的機密性、完整性與可用性。

## 2. 系統控制措施對應 (Control Measures Mapping)

| 法規/內控風險點 | 傳統痛點 | 本系統的數位化控制措施 (Digital Controls) |
| :--- | :--- | :--- |
| **高風險作業前檢驗** (Cap. 59) | 工友常因貪快省略紙本自檢，事後補簽。 | 透過 Forms 掃碼，強制完成 13 項核心高危檢驗（如工作許可證、高空防護、電力標籤）方可提交。 |
| **雙重責任制** (Accountability) | 出事時工友與工頭互相推諉，或偽造簽名。 | 表單強制要求「檢查工友」與「確認工頭」雙人實名電子簽認，綁定提交的 HKT 數位時間戳記。 |
| **實質安全覆核** (Supervisory Check) | 監工只在辦公室批核紙本，未實質巡查。 | 監工收到 Approvals 卡片後，必須點擊專屬連結，上傳現場巡查的「實景相片」作為核准佐證。 |
| **管理層最終防線** (Management Oversight) | 經理無法即時掌握全盤風險，容易發生未批先做。 | 狀態機阻斷機制：未經經理於 Outlook 點擊 Approve，系統狀態不會變更為「已批准/已歸檔」，嚴禁開工。 |
| **審計軌跡防篡改** (ISO 27001 - A.8.10) | 紙本紀錄易遺失或遭事後抽換塗改。 | SharePoint 狀態機結合 M365 底層審計日誌 (Audit Log)，所有狀態變更與經理批示均不可刪除或篡改。 |
