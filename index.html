📌 專案摘要 (Executive Summary)

This repository is an Enterprise Demo showcasing how to implement Frontline Safety Governance using M365 Low-Code and State Machine architecture.

EnterpriseDemo-SiteworksPSPJC 是一套針對工程與建築施工現場高風險作業安全管理設計的無紙化合規治理方案示範。

本專案徹底捨棄了傳統紙本巡查表與易出錯的 PDF 快照轉檔機制。以 Microsoft 365 原生生態（Forms、SharePoint Online、Power Automate 及 Approvals） 為基礎架構，在無需購買 Power Platform Premium 授權的前提下，實現「前線免登入掃碼填報 ➔ SharePoint 狀態機主數據庫 ➔ 現場監工實質初審 ➔ 項目經理終審放行 ➔ 助理與行政合規歸檔」的全自動化企業級安全閉環。

🏛️ 流程生命週期與治理閉環 (Workflow Lifecycle)

傳統地盤自檢流程的最大痛點在於「前線帳號登入繁瑣、審核滯後、無法即時叫停高風險違規作業」。本系統透過 SharePoint 狀態機（State Machine）與順序式審批，確保每一筆開工申請的狀態透明且絕對防竄改：

甲部・現場自檢
Forms 免登入填報
檢查工友與工頭掃碼完成 13 項高危項目自檢，並進行雙人電子簽認聲明。
乙部・監工初審
現場覆核與補件
監工查收審批卡片，點擊直達連結上傳現場相片，核實合格後按掣批准。
丙部・經理終審
開工最終決策
檢視完整數據與相片，簽發正式開工許可，或阻斷流程勒令現場整改。
丁部・合規歸檔
狀態機自動鎖定
清單狀態自動更新為「已批准/已歸檔」，全程免人工轉檔建檔。
丁部・合規閉環
正式派發許可證
系統發送包含完整審計鏈與決策備註的通知函予行政與監工留底備查。

📋 業務四部曲對照表 (Governance Matrix)

階段 責任角色 承載平台 處置動作與審計紀錄
甲部：現場自檢 工友 & 工頭 Microsoft Forms 透過 QR Code 免登入填報。完成 13 項高風險安全自檢（工作許可、高空作業等）並提交實名簽認。
乙部：監工初審 現場負責監工 Outlook / Teams Approvals 系統動態派發審批卡片至負責監工信箱。監工點擊直達連結巡視現場補充照片，確認後點擊 Approve。
丙部：經理終審 項目經理 自訂 Approvals 卡片 接收包含完整檢查摘要與監工意見之終審卡片，確認合規後簽發正式開工許可。若駁回則流程中斷並警告現場。
丁部：合規歸檔 助理 / HR SharePoint Online 僅在經理終審批核或否決時正式接收電郵通知。清單狀態機自動鎖定，備戰勞工處或業主安檢。

⚙️ 技術亮點與進階架構 (Technical Architecture)

1. 極簡前線採集 (Frictionless Capture)

針對工地前線可能無企業帳號的限制，採用 Forms 公開免登入設計，結合下拉式動態監工路由，達成掃碼即填的高效體驗。

2. SharePoint 狀態機 (State Machine)

運用 SharePoint List 作為關聯式數據庫與狀態機。全流程透過狀態節點（待監工審核 ➔ 待經理審核 ➔ 已歸檔）驅動，進度完全透明。

3. 主數據分離路由 (Master Data Driven)

設立獨立監工名冊清單。後台透過 OData Filter Query 動態解析監工電郵，人事異動時只需維護清單，無需修改自動化代碼。

4. 資訊疲勞過濾 (Anti-Fatigue Design)

取消過早的平行知會分支，行政人員僅需接收具備最終效力的經理決策結果，大幅消除管理雜訊與無效電郵。

5. 零額外授權架構 (Zero-License Cost)

全架構 100% 採用 Standard Connectors（Forms, SharePoint, Approvals），替企業省下高額 Premium 授權開銷。

6. 自動審計防護 (Automated Audit Trail)

狀態機設計從根本上防止前線竄改狀態，每一道審批節點皆於合規中心生成不可刪除之數位時間戳記與處置軌跡。
